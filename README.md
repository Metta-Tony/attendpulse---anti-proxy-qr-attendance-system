# AttendPulse

AttendPulse is a QR-based attendance system for campus lectures. It uses rotating signed tokens, device binding, geofencing, and audit logs to reduce proxy attendance and duplicate scans.

## Features
- Rotating QR attendance tokens
- Student and lecturer dashboards
- Device registration checks
- Venue geofence validation
- Duplicate scan protection
- Security audit reporting

## Run locally

Prerequisites: Node.js

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev`
3. Open the app in your browser at:
   `http://localhost:3000`
